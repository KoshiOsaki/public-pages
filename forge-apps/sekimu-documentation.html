SEKIMU Documentation

Page governance for Confluence · Updated October 30, 2026

PrivacySupport

What SEKIMU does: adds ownership, review due dates, lightweight approvals, stale-page discovery, and reminders directly inside Confluence.

Install and open

  1. A Confluence site administrator installs SEKIMU from Atlassian Marketplace.
  2. Open a Confluence page and select SEKIMU beneath the page title to view its governance state.
  3. Open Apps → SEKIMU to see your work and stale pages.

No separate account or external service is required.

Page ownership and reviews

Assign an owner

Editors can assign a responsible Atlassian user to a page. When an owner is first assigned, SEKIMU calculates a review due date from the site’s default review interval.

Set a review interval

Choose a periodic interval or disable periodic review for the page. Select Mark as reviewed after checking the content; SEKIMU records the reviewer and moves the next due date forward.

Approvals

  1. An editor selects between 1 and 10 reviewers and requests approval.
  2. SEKIMU posts a Confluence comment mentioning the reviewers.
  3. Each reviewer approves or rejects. A rejection requires a comment.
  4. When all reviewers approve, the page becomes approved. If the page changes later, SEKIMU shows that it was edited after approval.

This is a lightweight approval record, not a multi-stage workflow or a page-version lock.

Dashboard and reminders

My work shows overdue or soon-due pages you own and approvals waiting for your response. Stale pages lists pages that have not been updated within the configured period. Results are limited to pages the current user can view.

Scheduled reminders can mention owners or unanswered reviewers in page comments. Administrators can disable reminder comments or change the minimum repeat interval.

Site settings

Site administrators can configure the default review interval, how soon a review is considered due, the stale-page threshold, reminder comments, and the reminder repeat interval.

Permissions and data

SEKIMU respects Confluence view and edit permissions. Users without edit permission can view the governance state but cannot change it. Administrative settings require site-administrator access. For details, see the Privacy Policy.

Troubleshooting

  • SEKIMU is not visible: confirm that the app is installed for the current Confluence site and reload the page.
  • A control is read-only: confirm you have permission to edit the Confluence page.
  • A page is missing from a list: confirm you can view the page and that it meets the selected status or stale threshold.
  • A reminder did not appear: confirm reminders are enabled and the repeat interval has elapsed.
