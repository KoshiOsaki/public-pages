KAIDO

その日の締め切りを、怪獣に追われる一本道として見る macOS アプリ。

これは何か

画面の上端に細い帯として貼り付き、いま抱えている作業を道の上の人として並べます。 締め切りが近いものほど左（怪獣の側）に立ち、怪獣は現在時刻として右へ進みます。 追いつかれる前に終わらせるか、期限を延ばすか、後回しにするかを決める、という道具です。

  • 作業ごとの期限を一本の時間軸に並べる
  • 「後で」に送った分だけを別窓の一覧に貯める
  • Google カレンダーをつなぐと、その日の予定が道の上に帯として重なる

インストール

macOS 11 以降。ターミナルで次を実行します。

curl -fsSL https://raw.githubusercontent.com/KoshiOsaki/kaido/main/install.sh | bash

配布物とインストーラは GitHub に置いてあります。

カレンダー連携

予定を道に重ねたいときだけ、盤面の「カレンダー連携」ボタンから Google アカウントで 認証します。要求する権限はカレンダーの閲覧のみ （calendar.readonly）で、予定の作成・変更・削除はできません。

取得した予定はお使いの Mac の中だけで処理し、KAIDO の開発者を含む誰にも送信しません。 詳しくはプライバシーポリシーを参照してください。 連携をやめたいときは Google アカウントの「アプリとサービス」 からアクセス権を削除できます。
