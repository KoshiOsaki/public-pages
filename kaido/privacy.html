プライバシーポリシー

KAIDO（macOS アプリ）／ 最終更新: 2026-09-17

要約

KAIDO は利用者の Mac の中だけで動きます。サーバーを持たず、利用者のデータを 開発者へ送信することも、第三者へ提供・販売することもありません。

取り扱う情報

  • Google カレンダーの予定（カレンダー連携をした場合のみ）: その日の予定の表題・開始／終了時刻・出欠状態。権限は閲覧のみ （https://www.googleapis.com/auth/calendar.readonly）で、 予定の作成・変更・削除は行いません。
  • アクセストークン・リフレッシュトークン: カレンダーを読むために Google が発行する資格情報。
  • 利用者がアプリに入力した作業内容と期限。

利用目的

予定を当日の時間軸上に描画し、作業の期限と重ねて表示するためだけに使います。 解析・広告・プロファイリングには一切利用しません。

保存場所

上記の情報はすべて利用者の Mac のローカルディスクに保存されます （~/.local/state/postpone-desk/ 配下）。 トークンを書いた設定ファイルは所有者のみ読み書き可能な権限（600）で保存します。 外部のサーバーへ送信・保管することはありません。

第三者への提供

提供しません。KAIDO が通信する先は Google の API（カレンダーの取得と トークンの更新）だけです。

Google ユーザーデータの取り扱い

KAIDO による Google API から受け取った情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的な使用の要件を含む）に準拠します。

削除方法

  • 連携の解除: Google アカウントの「アプリとサービス」 から KAIDO のアクセス権を削除してください。
  • ローカルデータの削除: ~/.local/state/postpone-desk/ を削除すると、 トークンを含め KAIDO が保存した情報はすべて消えます。
